# Man-in-the-Middle Attack — VTU CNS Project

Interactive educational website for a VTU Cryptography and Network Security project.

## Features

- Explanation of Man-in-the-Middle attacks
- Alice–Mallory–Bob communication simulator
- Attack vs authenticated communication comparison
- Simplified Diffie-Hellman MITM mathematical demonstration
- Attack lifecycle
- Prevention techniques
- Responsive UI
- Pure HTML, CSS and JavaScript
- GitHub Pages compatible
- No backend or external libraries

## Run locally

Open `index.html` in a browser.

## GitHub Pages

Upload `index.html`, `style.css` and `script.js` to the repository root.

Then:

Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)

## Academic scope

The simulator is intentionally local and educational. It does not intercept traffic,
scan networks, exploit devices, or perform a real-world MITM attack.

The Diffie-Hellman section uses small fixed classroom values solely to visualize the
mathematical concept of unauthenticated key substitution.
